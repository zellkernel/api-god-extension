# Chrome Web Store assets

Listing images for **API-God — X export**. Kept in the repo so the store submission is reproducible.

| File | Size | Purpose | Store slot |
|---|---|---|---|
| `screenshot-1-panel.png` | 1280×800, 24-bit RGB, no alpha | Panel capturing an X search timeline | Screenshot 1 |

Constraints these files satisfy (Chrome Web Store, 2026):

- Screenshots must be **exactly 1280×800 or 640×400**, 24-bit PNG (or JPEG), **no alpha channel**.
- The store icon is a **separate 128×128 upload** from the icons packaged inside the extension.
